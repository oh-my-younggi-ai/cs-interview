# Step Query: 위키 질의

로드맵과 작성된 개념 페이지를 구분해 위키 내용을 찾아 종합한다. 파일 반영은 사용자 승인 후 진행한다.

## RULES

- 답변은 실제 개념 페이지 내용에 근거한다.
- 위키에 없는 내용을 보충하면 그 사실을 명시한다.
- `##` 큰 토픽은 학습 범위이지 정답 지식이 아니다.
- 질의 중 `{wiki_root}`는 읽기만 한다.

## INSTRUCTIONS

### 1. 관련 페이지 탐색

1. 루트 `index.md`에서 관련 분야 링크를 찾는다.
2. 분야별 `index.md`에서 관련 `##` 큰 토픽을 찾는다.
3. 큰 토픽 아래 실제 개념 페이지 링크만 작성 완료 지식으로 수집한다.
4. 필요한 개념 페이지만 읽는다.

### 2. 종합 답변

- 근거가 된 concept ID나 링크를 밝힌다.
- 분야 현황을 물으면 큰 토픽별 작성 개념과 비어 있는 영역을 구분한다.
- 제목만 있고 개념 링크가 없는 큰 토픽은 학습 영역은 있지만 작성된 개념은 없다고 설명한다.
- 큰 토픽 제목만으로 세부 내용을 만들어 위키 지식처럼 답하지 않는다.
- 관련 페이지가 없으면 알리고 지금 대화하거나 정리할지 제안한다.

### 3. 파일링 제안

위키에 남길 가치가 있으면 신규 작성이나 기존 페이지 갱신을 제안한다. 대상의
`분야 > 큰 토픽 > 개념`을 함께 제시한다. 사용자가 동의하면 `./step-ingest.md`를 따른다.
맞는 큰 토픽이 없으면 로드맵 변경안을 제시하고 별도 승인을 기다린다.

작업 완료 후 추가 요청이 있으면 `./step-01-route.md`로 다시 분류한다.
